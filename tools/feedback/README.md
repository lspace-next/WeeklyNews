# 독자 피드백 설정 (Google 스프레드시트 + Apps Script)

주차 페이지 하단의 "이번 호 어땠나요?" 블록이 보낸 응답을 Google 스프레드시트에 쌓는다.
`assets/js/main.js` 의 `FEEDBACK_URL` 이 비어 있으면 블록은 화면에 나타나지 않는다.

## 1. 시트와 스크립트 만들기 (최초 1회)

1. 회사 Google 계정으로 새 스프레드시트를 만든다 (예: `Tech Radar 피드백`).
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 [`Code.gs`](Code.gs) 를 그대로 붙여넣고 저장한다.
4. 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(톱니바퀴) → **웹 앱**
   - 설명: `feedback v1`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (익명 독자가 보내야 하므로)
   - **배포** → 권한 승인(“확인되지 않은 앱” 경고가 나오면 고급 → 이동) 
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사한다.
6. 브라우저에서 그 URL 을 열어 `L.SPACE Tech Radar feedback endpoint` 가 보이면 정상.

## 2. 사이트에 연결

`assets/js/main.js` 맨 위의 값을 채우고 커밋·푸시한다.

```js
const FEEDBACK_URL = "https://script.google.com/macros/s/.../exec";
```

## 3. 확인

- 주차 페이지 하단에서 👍 를 누르면 시트 `feedback` 탭에 행이 생긴다(처음엔 탭과 헤더가 자동 생성).
- 같은 브라우저에서 평가를 바꾸거나 의견을 보내면 같은 행이 갱신된다.

## 스크립트를 고쳤을 때

Apps Script 는 저장만으로 반영되지 않는다. **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**.
이렇게 하면 URL 은 그대로 유지된다. (“새 배포”를 만들면 URL 이 바뀌므로 main.js 도 바꿔야 한다.)

## 시트 컬럼

| 접수시각 | 호 | 평가 | 의견 | 세션 | 수정시각 |
|---|---|---|---|---|---|
| 첫 응답 시각 | `2026-10-w2` | `good` / `soso` / `bad` | 자유 의견(최대 500자) | 브라우저별 임의 ID | 마지막 수정 |

이름·이메일·IP 는 수집하지 않는다.
